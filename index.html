ℹ️ About StudentMate

StudentMate is an all-in-one student productivity application designed to keep common academic tools in one place.

It combines notes, tasks, reminders, routine, calculator, GPA tools, marks calculator, study timer and formula reference.

The application is designed with an offline-first approach. Most personal information created inside the app remains in the browser/device storage.

Version: 2.0.0

Developer: StudentMate Project

🔒 Privacy Policy

StudentMate respects your privacy. The application is designed to minimize unnecessary collection of personal information.

1. Information Storage

Notes, tasks, routine information, calculator history and application preferences may be stored locally on your device using browser local storage.

2. No Account Required

The basic application does not require a username, password or account to use its offline features.

3. Permissions

Optional permissions such as notifications, camera, microphone or location are requested only when a corresponding feature needs them. Permission availability depends on the browser or Android WebView environment.

4. Notifications

If notification permission is granted, StudentMate may use browser notifications for supported reminder features. Notifications are not guaranteed when the application is fully terminated unless the Android wrapper provides a native background notification service.

5. Data Sharing

The basic offline features do not intentionally upload your notes, tasks or routine to a StudentMate server.

6. Third-Party Services

This single-file version does not require external analytics or advertising services for its core features.

7. Data Deletion

You can remove locally stored application data using the Clear All App Data option. Clearing browser/WebView data can also remove locally stored information.

8. Student Privacy

Users should avoid entering highly sensitive information, passwords, financial credentials or other confidential information into ordinary notes.

9. Policy Changes

This privacy information may be updated when application functionality changes.
